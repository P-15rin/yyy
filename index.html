読み込み中…

この端末で初めて開いています。リンクを保存する非公開リポジトリ（linkboard）を読み書きするための「鍵」を、端末ごとに1回だけ貼り付けてください。

  1. 鍵の作成ページを開く（名前や権限は入力済みです）
  2. 「Repository access」で Only select repositories を選び、linkboard を選ぶ
  3. 一番下の緑の「Generate token」を押し、表示された github_pat_ で始まる文字列をコピー
  4. 下の欄に貼り付けて「保存」
